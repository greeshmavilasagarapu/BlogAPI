# BLOGAPI

## Features
- Create a blog
- Read a blog
- Update a blog
- Delete a blog

## Technologies Used
- HTML
- Go

## Installation
1. Clone or download the project to your local machine
2. Install dependencies:

   ```bash
   npm install
   ```

## Run the Project
2.Compile and run the Go backend:
```bash
go run main.go
```
*(Note: Replace `main.go` with the actual name of your entry file if it is different).*
